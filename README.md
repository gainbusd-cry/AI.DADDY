# 🚀 AI.DADDY - AI Advertisement Generator (MVP)

Welcome to the MVP version of *AI.DADDY*, a SaaS utility platform built for small businesses, dropshippers, and marketers to generate high-converting ad copies instantly using AI.

This initial tool takes simple business details and outputs optimized copies for Facebook, Instagram, Google Ads, along with powerful Call-To-Actions (CTAs).

---

## 🛠️ Tech Stack & Architecture

- *Frontend:* HTML5, JavaScript (Fetch API), Tailwind CSS (via CDN)
- *Backend:* PHP (Native / Vanilla PHP)
- *AI Engine:* Google AI Studio (Gemini 1.5 Flash API)
- *Hosting:* Hostinger Cloud
